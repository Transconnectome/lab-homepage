# 홈페이지 개편 실행 계획 — 2026-10-02

목표: 연구실 정체성, 실제 연구, 지원 경로를 빠르게 이해할 수 있는 한영 홈페이지. 평가 문서의 출처 오류를 우선 해결하고 차분한 편집 디자인을 유지한다.

1. 고정 소개와 연구·논문·지원 링크를 첫 화면에 배치한다. 대표 그림은 검토된 MBBN A–C 발췌·원출처·해석 한계로 연결한다.
2. 네 연구 질문과 설명은 검토된 research 컬렉션을 직접 사용한다. 일일 화두는 같은 컬렉션의 질문을 선택해 보여주며 고정 소개를 바꾸지 않는다. 긴 연구관은 선택 읽기로 연결한다.
3. 사람·지원·소식은 짧은 목록으로 정리한다. 출처 없는 PI 직접 인용, 모집 보장, 별도 주소와 참고 그림의 연구성과 표시는 제거한다. 공식 안내는 기존 상세로 연결한다.
4. 홈의 중복 BibTeX 기능 대신 기존 논문 페이지의 인용 기능으로 안내한다. 화두는 기본 링크를 제공하고 JS에서 일반 버튼 그룹으로 향상해 키보드 사용과 JS 없는 접근을 보존한다.
5. 한영 빌드·사이트 계약·브라우저 화면·키보드·링크·화두 날짜 선택을 검사한다. 두 읽기 전용 검토자의 콘텐츠/비판 검토를 반영한다.

범위: 홈, 화두 데이터 구조, 개편 기록. 검토된 상세 본문과 기존 URL은 보존. 운영 배포·워크플로 변경은 이번 실행에 포함하지 않는다.

완료 기준: 잘못된 서지/인과/치유 서사 미노출, 홈과 상세 질문 일치, 모바일 첫 화면의 지원 링크, 한영/320·390·1440px 가로 넘침 없음, 일일 주제 선택과 일반 키보드 활성화, 기존 테스트 통과.

## 실행 결과

구현 완료: 고정 소개·첫 화면 지원 링크, MBBN A–C 발췌와 정확한 크레디트, 컬렉션 기반 네 질문·화두, 선택 읽기, 간결한 구성원·지원·소식 목록. 화두는 빌드뿐 아니라 브라우저에서도 KST 날짜를 계산하며 버튼은 Enter/Space로 선택한다. JS가 없으면 네 상세 링크가 남는다. 학술 인용은 기존 논문 페이지로 통합했다.

초기 검증: npm test, build, test:site 성공. 한영 320/390/1440px 6화면에서 넘침·pageerror 0, 네 버튼과 JS 없는 링크 확인. 390px 한국어 홈 높이 12,608→5,779px, 소식 위치 9,424→3,583px. 후속 독립 검토에서 동적 버튼 CSS 스코프 누락을 고쳤고 최종 빌드·사이트 계약 및 버튼 크기(44×44px)/선택색을 재확인했다. 일일 함수의 KST 자정 경계 확인 완료.

최종 재검사: 한영 6화면 모두 통과. 버튼 스타일 반영 후 390px 한국어 높이 5,795px, 소식 y=3,600px(초기 측정 대비 소폭 변화). 재검사 중 이미지 대기는 부드러운 스크롤과 지연 로딩 때문에 한 차례 시간 초과했다. 재현 스크립트를 reduced-motion과 이미지별 decode 대기로 바꾼 후 모든 이미지와 화면 검사가 완료됐다. 최종 버튼 크기는 모바일·데스크톱 모두 44×44px이며 선택색도 확인했다.
